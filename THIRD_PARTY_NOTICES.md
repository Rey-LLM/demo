# Third-party notices

ftviz.exe is one static binary. This file lists every third-party library
linked into it and every dataset embedded in it, with its license. A dataset
whose license does not clearly allow redistribution is not embedded.

|---|---|---|---|
| GLFW | 3.4 | zlib/libpng | https://github.com/glfw/glfw |
| glad (generated GL 4.5 core loader) | 2.0.8 | generator MIT; generated loader public domain / CC0 / WTFPL, Khronos XML-derived parts Apache-2.0 | https://github.com/Dav1dde/glad |

The full license texts are in each project's repository at the version
above; FetchContent places them under `build/_deps/<name>-src/` at build
time.

## Embedded datasets

| Dataset | Used for | License | Status in this tree |
|---|---|---|---|
| Natural Earth 1:110m and 1:50m coastlines, v5.1.2 | coastlines (`assets/coastlines_*.bin`) | public domain | embedded |
| BIS Triennial Central Bank Survey 2022, OTC FX turnover shares | MODELED fiat corridors (`config/flows_baseline.csv`) | figures cited with attribution; BIS permits reproduction with the source stated | embedded (a handful of published shares, source URL per row) |
| Trading hours and holidays of TSE, LSE, NYSE/Nasdaq, SSE | session states (`config/sessions.json`) | facts from the exchanges' public calendars; each entry carries its source URL | embedded; holidays marked UNVERIFIED until checked against each source |
| NASA Black Marble (night lights) | city lights (`assets/citylights.bin`, BC4, log-toned) | NASA imagery is not copyrighted (NASA media usage guidelines); credit "NASA Earth Observatory" | **not embedded yet**: the build machine has no route to NASA's servers. The layer is off until `tools/build_citylights.py` has been run on the downloaded image |
| Submarine cable routes | cable hairlines and MODELED routes (`assets/cables.bin`) | must be redistributable; TeleGeography's Submarine Cable Map data is CC BY-NC-SA 3.0 (non-commercial) and is **not** used | **not embedded yet**: candidate is OpenStreetMap `communication=line` + `location=underwater` / `submarine=yes` ways, ODbL 1.0, which requires attribution "© OpenStreetMap contributors" and that the derived `cables.bin` be offered under ODbL |
| Replay capture `assets/replay/default.ftxcap` | offline fallback, `--replay` | generated by `tools/gen_capture.cpp`; synthetic, no third-party data | embedded |

Time zones: the binary embeds no time-zone database. On Windows the C++20
`std::chrono` time-zone functions read the operating system's ICU data; on
Linux, the system tzdata.

When a dataset above changes from "not embedded" to "embedded", this file
records the exact source URL, retrieval date and license text location in
the same commit.
